# IQRS Workspace Desktop app

Goal ID: goal_0e3dbfe67a02
Goal slug: iqrs-workspace-desktop-app

## Description
Build a native JavaFX desktop app in the same design as the IQRS mobile apps, with full offline access through an encrypted per-login SQLite database. It reuses the mobile API and push-sync layer, adds a new Staffpull delta-sync service, and proceeds through sync foundation, Workspace v1, fees and printing, then Connect Desktop and a school-office pilot.
