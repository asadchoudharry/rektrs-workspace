# IQRS school mobile app

Goal ID: goal_fce934af3998
Goal slug: iqrs-school-mobile-app

## Description
Build separate Student & Parent and Teacher/Staff/Admin mobile apps for the IQRS school management system at iqrs.edu.pk, whose web app is already built and live in production. The apps must carry the school's identity kit and branding, connect to the live web app via the now-deployed production API, and include all web-app features with separate sign-in for each group. They must be fully designed in new technology with no WebView, use the new pastel reference design, include role-based QR code attendance for staff, and give the admin app offline sync for attendance, homework, notices, and fee collection.
