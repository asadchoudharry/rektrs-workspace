# Admin Template Comparison — Operqon Portal / Console / Tenant ERP

**Prepared:** 2026-11-14, by Muse, on the owner's request.
**Question:** one (or two) HTML admin templates to buy as design raw material for Operqon's
three surfaces — **customer portal**, **Super Admin console**, **tenant ERP dashboards**
(modules needed: Finance, CRM, Inventory, HRM, POS, Projects, Payments).
**Method:** every candidate checked on the same criteria — tech (framework/SCSS/JS),
pages & verticals, ERP module coverage, Dark/Light, RTL, Figma, font/icons/charts,
freshness, vendor record. Facts verified from ThemeForest item pages, vendor docs and
live demos, 2026-11-13/14. Envato Elements availability of specific items could **not**
be verified (Elements pages are script/login-walled) — check there before downloading
if you hold an Elements subscription; all prices below are ThemeForest.
**Benchmark:** Dreams Core (Dreams Technologies) was evaluated in the previous step and
is included as the first row.

## Excluded — checked, not recommended

- **Bankco** (wowtheme7, $12) — banking-niche only (transactions/accounts/cards/loans),
  Tailwind 3.3, **frozen since Oct 2023**, 40+ pages, no SCSS, no ERP modules. At most a
  visual reference for a finance screen.
- **Vuesy** (themesdesign, Bootstrap 5.3.3 + SCSS, RTL ✓) — competent but a design
  generation behind; e-commerce apps only, no ERP modules.
- **Nazox** (themesdesign, Bootstrap + SCSS, RTL ✓) — Projects/Tasks/Invoices coverage is
  useful, but the visual system is the plainest of the set; heaviest re-skinning cost.
- **Stexo** (themesdesign) — pure-HTML item stale since Dec 2023. Legacy.
- **Metoxi / Skodash / Rukada** (codervent) — near-duplicates of Rocker with weaker
  records; buying more than one codervent item adds nothing.
- **Fillow / Fasto / Vora** (DexignZone/dexignlabs) — dormant (last updates 2023/2022/2022).
- **themesdesign as a vendor** — 440 items but author rating **3.88★** and Tailwick itself
  3.59★: uneven code/support quality across the catalogue. Tailwick stays on the
  shortlist on its own merits; the vendor's Bootstrap lines do not.

## Reading the table — what actually decides it

- **Tenant ERP dashboards** are the hard surface: only **Dreams Core** ships real
  Finance / CRM / Inventory / HRM / Projects / Payments verticals. Every Bootstrap
  candidate covers at most CRM + Projects and leaves the ERP core to be designed from
  scratch anyway.
- **Direction match:** Dreams Core is the same vendor family as the settled direction
  (Dreams ERP / DreamsPOS) and uses **Geist** — the font already chosen for the ERP.
  No other candidate matches the settled look; all would be re-skinned into it.
- **Console + Portal** are easier surfaces: W3CRM's account suite (billing, API keys,
  security, logs) and WowDash's breadth (roles & permission pages, help desk, SaaS demo)
  map best onto them; Tailwick is the most modern-looking Tailwind option for these two.
- **RTL** is confirmed only on Dreams Core, WowDash Tailwind, YashAdmin, Tailwick,
  Vuesy, Nazox. It is *unconfirmed* on WowDash Bootstrap, W3CRM and all of codervent.
- **Figma** is bundled by nobody on this list with certainty (Tailwick lists it as a
  variant; DexignZone and wowtheme7 sell Figma files separately for ~$19). Plan on the
  Figma screens being built from the HTML either way — as was done for the v3 programme.
- **JS:** everything except Dreams Core is jQuery-based. That is acceptable — markup and
  SCSS are what get reused; JS is rewritten into our vanilla/token system regardless.

## Licensing note (important)

ThemeForest's **Regular License** covers an end product whose end users are **not
charged**; Operqon's tenants pay, so the safe route for whichever template is chosen
is the **Extended License** (e.g. W3CRM Extended is listed at $400–599; check the chosen
item's Extended price on its page). This is a one-time cost and does not change the
ranking — but buy the right license the first time.

## Recommendation (Muse)

1. **Buy Dreams Core ($16) as the primary template.** It is the only candidate that
   covers the tenant ERP modules, it matches the settled Dreams direction and Geist
   typography out of the box, has full RTL + dark mode, vanilla JS (our exact stack),
   and 400+ pages to mine for the console and portal as well. Its one weakness is
   newness (v1.0, ~70 sales) — acceptable for design raw material, since we adapt
   rather than ship its code.
2. **Optionally add ONE Bootstrap/SCSS second source ($10–19)** for console/portal
   patterns and SCSS reference: **WowDash Bootstrap** if breadth + price matter most
   ($10, 4.80★, Finance/POS/Project demos, roles & permissions pages), or **W3CRM**
   if the account/billing/API-key suite matters most ($19, 770 sales, 4.79★).
3. **Skip** Bankco, the codervent family beyond a single item, and themesdesign's
   Bootstrap lines. If a Tailwind alternative to Dreams Core is ever wanted for the
   portal alone, **Tailwick** is the fallback — with its 3.59★ item rating noted.
