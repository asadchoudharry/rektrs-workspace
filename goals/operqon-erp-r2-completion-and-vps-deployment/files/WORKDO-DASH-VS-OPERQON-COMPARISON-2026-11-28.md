## 2. Feature comparison — small-business needs

| Need | Operqon (today, live through oc71) | WorkDo Dash SaaS (current version) |
|---|---|---|
| Invoicing & billing | Strong — ERPNext sales/purchase invoicing, taxes, payment schedules; proven live in E1–E7 | Good — invoices, bills, recurring invoice addon; simpler, SMB-shaped |
| POS | Present in ERPNext; tenant-facing surface is still largely Desk-side, own SPA surface thinner | **Built into the base**, barcode/walk-in sales, designed for shop counters |
| Simple inventory / stock | Very deep — full stock ledger, warehouses, valuation; arguably heavier than a small shop needs | Inventory addon: multi-warehouse, reorder alerts, FIFO/LIFO/WA COGS — right-sized for SMB |
| Accounting depth | **Deepest of the two** — true double-entry GL, chart of accounts, financial statements, budgets (E7 Finance live) | Base accounting is basic (income/expense); the **Double Entry addon** adds GL/P&L, but it is still shallower than ERPNext |
| HR & payroll | ERPNext HR/payroll exists but is Desk-bound for tenants today; own-UI surface thin | **HRM in the base** (employees, payroll, attendance, leave) + Recruitment/Rotas/Training addons, all in the tenant UI |
| CRM / leads | ERPNext CRM exists; mostly Desk-side today | **Lead/CRM in the base** (leads, deals, pipelines) + Sales addon (quotes → orders → invoices) |
| Projects / tasks | ERPNext Projects exists; Desk-bound | **Taskly in the base**, tenant-facing out of the box |
| Support tickets | No real tenant-facing helpdesk today | Helpdesk listed in the base + Support Ticket addon (categories, FAQ, custom forms) |
| WhatsApp integration | Not built in; would be custom work (our Sendqon stack is a separate product) | **WhatsApp API addon ($49/$24)** — event notifications out of the box; Twilio variant also available |
| Multi-workspace SaaS + plans/subscriptions | Our own build: provider console + customer portal live (Aureus shell OS-80…OS-89), entitlement system, per-app/per-integration pricing model | **The product's core purpose**: super-admin, workspaces, plans, addon-to-plan assignment, subscription billing built in |
| Payment gateways | Few; integrations are custom-built one by one (service-provider model) | **60+ gateways claimed**, incl. Stripe, PayPal, PayTabs, Tap, Razorpay — Gulf-relevant ones included; no PK-local (JazzCash/Easypaisa) gateway seen |
| Saudi ZATCA e-invoicing | Not present; would be custom work | **Present** — `salla/zatca` library in the core dependencies (per our audit) plus a dedicated ZATCA addon on workdo.io (addon price not verified) |
| Arabic / Urdu UI | Arabic available via ERPNext translations; Urdu partial | 15+ languages with **full RTL support** claimed (Arabic workable); Urdu not specifically listed — a translation pass would be needed |
| Mobile access | Responsive web SPA; no native app | Responsive web; native mobile apps are sold separately on workdo.io (price not verified) |
| SSO / identity | **Rektrs ID (Keycloak) SSO live** at login.rektrs.com across console, portal, tenants | Own built-in auth; social-login addons exist; Keycloak/OIDC SSO would be custom work |
| Ownership & control | **Fully ours** — open-source Frappe/ERPNext base, our code, no vendor | Full source code, white-label rights under the Extended licence; but the roadmap and updates are WorkDo's, and the IP stays theirs |

## 3. Switching cost — if WorkDo became the base

**Would have to be rebuilt (does not transfer from the Frappe stack):**

| Item | Size | Note |
|---|---|---|
| Rektrs ID / Keycloak SSO into Laravel | **Medium** | Laravel side needs an OIDC/SAML integration (Sanctum/JWT are built in, Keycloak is not); alternatively drop SSO for tenants and keep Keycloak only for staff — a product decision |
| Provider console + customer portal | **Medium–Large** | Our Aureus console/portal (OS-80…OS-89) is built against the Frappe provider API. WorkDo's own super-admin covers much of the function (tenants, plans, addons) but not our exact screens, entitlement logic or per-app/per-integration pricing model |
| Tenant provisioning & deployment pipeline | **Medium** | The ocXX image train, pairing and deploy discipline are Frappe-specific; a Laravel deploy pipeline is simpler but new |
| Branding / white-label | **Small** | WorkDo is sold as 100% white-label (logo, colours, domain); applying the Operqon/Rektrs brand is configuration-level work |
| Data migration | **Small (today)** | Only demo tenants (demo2, rams) exist — no paying customer data to move. This is the cheapest this switch will ever be |

**Carries over unchanged:** the domains and DNS, Keycloak itself (as the identity server, if SSO is kept), the business model (per app + per integration, per user per month — WorkDo's plan/addon assignment maps onto it well), the customer portal concept, and everything outside the ERP base (Sendqon, Postqon, Rektrs ID infrastructure).

**Ongoing cost of the switch:** we would depend on WorkDo for core updates and security patches (the audited 2024 snapshot already needed a security-update pass — vendor pace matters), and deep customisation means maintaining a fork of someone else's Laravel codebase instead of our own Frappe apps.

---

## 4. Bottom line

For a **small-business** market, WorkDo Dash is the faster, broader product: POS, HRM, CRM, projects, helpdesk, WhatsApp and ZATCA are in the box for a **one-time $938 at list (about $793 at today's sale prices), $0 recurring**, under the $499 Extended licence — while Operqon still has to build or surface most of that breadth. Operqon wins on accounting depth, ownership and our Keycloak SSO, none of which a small shop will pay extra for. The honest trade: WorkDo buys speed and breadth at the price of a vendor-dependent base and a medium-sized rebuild of SSO + console; with no paying tenants yet, that rebuild has never been cheaper than it is right now. If the decision is "SMB first, factories never", the numbers support buying the Extended licence + essential addons (skip the $3,999 bundle until a second industry module is actually needed).
