## What a "Blueprint" is here
NOT a Zender template/flow/campaign or any importable file. The page's own
heading: "Pitch ideas, back the ones you want built, and track their
progress." A Blueprint is a **community product pitch** for a new self-hosted
SaaS/platform Titan Systems might build. Contents: title, overview (max 500
chars in the compose form), problem, solution, target audience, key features,
inspiration/competitor links, design-file mock-ups (PNG/JPG/WebP/PDF),
comments, and "Useful / Not useful" votes.
Lifecycle: Proposed → Researching → Funding → In Development → Released
(or Rejected). In Funding, customers reserve one of a limited number of
slots via "Join Funding" — no price/amount was displayed on any page.
No Zender install/import steps, file format, plan or licence requirement
exists for Blueprints anywhere on the portal.
